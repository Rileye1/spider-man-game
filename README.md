# 🕷️ Spider-Man: No Way Home - 3D Fighting Game

A complete 3D Spider-Man fighting game built with **Three.js** that runs entirely in your browser. No installation, no admin passwords, no terminal needed—just open and play!

## 🚀 Quick Start

### Play Online
👉 **[LAUNCH GAME HERE](https://rileye1.github.io/spider-man-game/)**

### Play Locally
1. Clone this repository
2. Open `index.html` in any modern browser
3. Start fighting!

## 🎮 How to Play

| Control | Action |
|---------|--------|
| **A / D** | Move Left / Right |
| **SPACEBAR** | Fire Web Attack |
| **W** | Jump / Dodge |

## 🎯 Objective

- **Defeat the Green Goblin** by hitting him with web attacks
- **Avoid his Pumpkin Bombs** to stay alive
- **Reduce his HP to 0** to win the game

## ✨ Features

- ✅ Full 3D graphics with Three.js
- ✅ Procedurally generated city backdrop
- ✅ Physics-based gameplay (gravity, collision detection)
- ✅ AI boss with attack patterns
- ✅ Real-time HP tracking
- ✅ Works in any modern browser (Chrome, Firefox, Edge, Safari)
- ✅ No external dependencies—runs purely in the browser
- ✅ Responsive design (desktop optimized)

## 🛠️ Technical Stack

- **Three.js r186** - 3D Graphics Engine
- **Vanilla JavaScript** - Game Logic
- **HTML5 Canvas** - Rendering

## 🎨 Game Elements

- **Spider-Man** (Red & Blue Character) - Player controlled
- **Green Goblin** (Green Character on Hoverboard) - AI Boss
- **Web Projectiles** (White Spheres) - Player attacks
- **Pumpkin Bombs** (Orange Spheres) - Boss attacks
- **City Backdrop** - Procedurally generated buildings
- **Platform** - Main fighting arena

## 📊 Game Stats

- **Player Max HP**: 100
- **Boss Max HP**: 100
- **Web Damage**: 8 HP per hit
- **Bomb Damage**: 15 HP per hit
- **Boss Attack Rate**: Every 1.5 seconds
